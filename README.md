# Uranium Age

## How to use?
  Install the mod's .jar file from modrinth and paste/add it into your minecraft instance's Mod folder. This mod currently only works on the the minecraft version 26.1.2 using the fabric loader and fabric api, so it will only work on a fabric minecraft isntance.
  
## Description
  This mod adds _Uranium_ and reactors to the game, which the player can use and benifit from. For a more detailed description check out my [Modrinth page](https://modrinth.com/mod/uranium-age).
  Bellow is a concise description of the blocks and items added into the game.

- ### Boron
  Boron, a crutial item to have for reactors. Can be mined with an Iron Pickaxe
  ![Boron far](https://github.com/mubduster/Uranium-Age/blob/main/Screenshots/boron_far.png)
  ![Boron close](https://github.com/mubduster/Uranium-Age/blob/main/Screenshots/boron.png)
  ![Boron mine](https://github.com/mubduster/Uranium-Age/blob/main/Screenshots/boron_mine.png)

- ### Lead
  Lead, a crutial item to have when working with _Uranium_.
  ![Lead far](https://github.com/mubduster/Uranium-Age/blob/main/Screenshots/lead_far.png)
  ![Lead close](https://github.com/mubduster/Uranium-Age/blob/main/Screenshots/lead.png)
  ![Lead mine](https://github.com/mubduster/Uranium-Age/blob/main/Screenshots/lead_mine.png)

- ### Lead Armor
  Lead Armor, can be crafted using Lead. A full set can be used to block radiation.
  ![Lead Armor stand](https://github.com/mubduster/Uranium-Age/blob/main/Screenshots/lead_armor_stand.png)
  ![Lead Armor player](https://github.com/mubduster/Uranium-Age/blob/main/Screenshots/lead_armor_player.png)

- ### _Uranium_
  _Uranium_, very useful for fission reactions and is very radioactive. Can be mined with an Iron Pickaxe. If a _Uranium_ Block is exposed to air or other Tarnished _Uranium_ blocks, then it will oxydize and turn into a Tarnished _Uranium_ Block.(Tarnished _Uranium_ Block is the block on the far right, in the first two images.) 
  ![_Uranium_ far](https://github.com/mubduster/Uranium-Age/blob/main/Screenshots/uranium_far.png)
  ![_Uranium_ close](https://github.com/mubduster/Uranium-Age/blob/main/Screenshots/uranium.png)
  ![_Uranium_ mine](https://github.com/mubduster/Uranium-Age/blob/main/Screenshots/uranium_mine.png)

- ### Portable Reactors
  How else are you going to fuel your furnaces? Can be used to fuel Furnaces, Blast Furnaces, and Smokers.
  ![Portable Reactors craft](https://github.com/mubduster/Uranium-Age/blob/main/Screenshots/portable_reactors.png)
  ![Portable Reactor furnace](https://github.com/mubduster/Uranium-Age/blob/main/Screenshots/portable_reactor_furnace.png)
  ![Portable Reactor blast furnace](https://github.com/mubduster/Uranium-Age/blob/main/Screenshots/protable_reactor_BF.png)

  - **Portable _Uranium_ Reactor**: Can be crafted using a, Portable Reactor Body, Reactor Boiler Small, and Reactor Core small.
  - **Portable _Uranium_ Block Reactor**: Can be crafted using a, Portabek Reator Body, Raector Boiler Large, and Reactor Core Large.
  
- ### Reactor
  A NUCLEAR FISSION REACTOR! Generates heat using a Fission reaction. Can be used to run Furnaces, Blast Furnaces, and Smoker.
